## Как получить API-ключ
1. Зарегистрируйтесь на сайте [exchangerate-api.com](https://www.exchangerate-api.com/).
2. Подтвердите email.
3. Скопируйте API-ключ из личного кабинета.
4. Вставьте ключ в строку `api_key = "ВАШ_API_КЛЮЧ"` в файле `currency_converter.py`.

## Примеры использования
1. Конвертация 100 USD в EUR (ожидаемый результат: ~92–94 EUR).
2. Конвертация 5000 RUB в USD (ожидаемый результат: ~54–56 USD).
3. Проверка валидации: ввод отрицательного числа или нечислового значения должен выдавать ошибку.

## Установка
1. Установите зависимости: `pip install -r requirements.txt`.
2. Запустите приложение: `python currency_converter.py`.

## Особенности
- Сохранение истории конвертаций в файл `conversion_history.json`.
- Отображение истории в таблице GUI.
- Валидация ввода (только положительные числа).
- Использование внешнего API для актуальных курсов валют.
